## 🔄 Cambios Importantes

Esta aplicación ha migrado de **Python/Flask** a **Next.js/React**. Los principales cambios incluyen:

- **Frontend**: Ahora usa React con Next.js para rendering del lado del servidor
- **Backend**: API Routes de Next.js en lugar de Flask
- **Estilizado**: Tailwind CSS para diseño moderno y responsivo
- **TypeScript**: Mayor seguridad de tipos y mejor experiencia de desarrollo
- **Arquitectura**: Aplicación full-stack moderna con hot-reload

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Configurar token de GitHub
# Crear .env.local y agregar: GITHUB_TOKEN=tu_token_aquí

# Iniciar servidor de desarrollo
npm run dev

# Abrir http://localhost:3000
```
